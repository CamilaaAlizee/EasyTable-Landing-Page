La Landing Page de Table Easy funciona como la puerta de entrada a nuestra solución digital. 
Permite a los usuarios explorar y realizar reservas de restaurantes de manera rápida, inteligente y personalizada.
Presenta la propuesta de valor, las funcionalidades principales, información del equipo y un chatbot interactivo que mejora la experiencia del usuario.
