La Landing Page de Table Easy funciona como la puerta de entrada a nuestra solución digital. 
Permite a los usuarios explorar y realizar reservas de restaurantes de manera rápida, inteligente y personalizada.
Presenta la propuesta de valor, las funcionalidades principales, información del equipo y un chatbot interactivo que mejora la experiencia del usuario.

Características Principales

Reserva Inteligente: permite hacer reservas en tiempo real.

Comparador de precios: muestra opciones según presupuesto.

Exploración virtual: permite visualizar el ambiente antes de asistir.

Recomendaciones personalizadas: según gustos y ubicación.

Chatbot interactivo: soporte inmediato dentro de la página.

Diseño responsive: adaptable a celulares, tablets y PC.

Interfaz moderna: uso de colores, animaciones y una estructura clara.
